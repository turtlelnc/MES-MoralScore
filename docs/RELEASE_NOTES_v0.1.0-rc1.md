# MES-MoralScore v0.1.0-rc1（build 26103101）发布说明

发布日期：2026-10-31 · 预发布（Release Candidate）· MIT License

MES-MoralScore（校园德育量化）首个候选版本：面向中小学校德育处/政教处、系统管理员与值日老师的 Node.js 全栈德育管理平台。本版本完成「规则版本 → 快捷记分 → 复核 → 学生干部申报 → 申诉裁决 → 成长报告/家长只读分享 → 数据分析」的完整闭环，并提供导入导出、真实备份与只追加审计日志。

## 本版本内容

### 三类核心角色与服务端授权

- 固定三类角色：系统管理员（SYSTEM_ADMIN）、德育处/政教处（MORAL_AFFAIRS）、值日老师（DUTY_TEACHER）。
- 每个 API 在服务端校验角色与数据范围（值日老师仅授权年级/班级）；防 IDOR，越权 403/404，不在错误中泄露其他班学生信息。
- 系统管理员不能绕过德育处发布评分标准；申诉裁决仅德育处；管理员不能停用或降级自己。

### 规则版本与生命周期

- 分类与规则管理：DRAFT → SUBMITTED → APPROVED → PUBLISHED → ARCHIVED，驳回可回到草稿。
- 已审核/已发布版本不可静默修改（数据库触发器兜底）；修改必须生成新版本，发布后不可再改生效时间。
- 记录写入时保存规则快照，历史记录解释不随改版变化。
- 记分仅接受当前有效、范围（全校/年级/班级）匹配的已发布版本。

### 不可篡改积分账本

- 整数分值；`学期得分 = 初始分 + Σ已生效加分 - Σ已生效减分`；初始分/是否允许负分/复核阈值可配置。
- `EFFECTIVE` 记录在数据库层禁止 UPDATE/DELETE；撤销只能追加冲正（REVERSAL），更正为冲正 + 更正（CORRECTION）；同一记录仅允许一条生效冲正。
- 待复核策略：规则要求复核 / 达到复核阈值 / 竞赛荣誉加分自动进入德育处复核队列；待复核与驳回记录不计分。
- 批量记分事务化（全有或全无），返回逐条结果；CSV 导出按当前筛选与权限范围。

### 快捷记分（移动优先）

- 选择学生（班级筛选/搜索/多选批量）→ 选择规则 → 填写说明与证据 → 二次确认 → 提交。
- 证据私有存储、文件头类型校验、随机文件名、授权下载。
- 高影响操作二次确认，待复核结果明确提示。

### 学生干部申报（不直接改分）

- 班级级申报链接：高熵 token、仅存哈希、可撤销/过期、使用次数统计。
- 学生以学号 + 姓名校验提交，错误信息不区分学号不存在/姓名不匹配；不暴露名册。
- 申报一律待核实；值日老师选择已发布规则核实通过后才生成积分记录；驳回/要求补充必须填理由。

### 申诉中心

- 仅对已生效记录发起，同一记录仅一个未结申诉。
- 受理/裁决仅德育处；裁决理由必填；裁决人与原记录提交人相同时记录利益冲突并要求例外说明。
- 接受申诉通过 REVOKE（仅冲正）或 REPLACE（冲正 + 更正）处理，原记录永不改写；裁决记录只追加。

### 数据分析与成长报告

- 仪表盘：真实 KPI、加减分趋势、班级人均分对比、年级分布、分类构成、异常提醒（24h 减分异常、大额记录、7 天无记录班级）与待办入口。
- 多维分析：学期/时间范围/年级/班级筛选，本期 vs 上期对比、规则排行、分类归因、下钻。
- 学生周报/月报/学期报告：积分构成、趋势、亮点表现、中性措辞的关注项、规则解释、荣誉与兑换参考、确定性中文叙事；打印与 CSV 导出。
- 班级报告：人均分、学生列表、分类与趋势、加分/关注规则排行。

### 家长只读分享

- 高熵分享 token（库中仅存哈希）、1–90 天有效期、撤销、访问日志与访问计数。
- 公开报告只展示该学生数据：不展示班级排名、其他学生信息或后台入口；脱敏学号；过期/撤销统一 404。
- 家长入口为只读，不提供任何修改能力。

### 导入、导出、备份与审计

- 学生/班级/教师 CSV 导入：预览、逐行错误明细、事务提交（失败不产生半批脏数据）、错误 CSV 与模板下载、UTF-8 编码校验。
- 列表/报表 CSV 导出（UTF-8 BOM、公式注入防护、范围受权限限制）。
- 真实 SQLite `VACUUM INTO` 备份：CLI（`npm run backup:run` / `backup:status`）与系统管理手动触发，展示真实状态/大小/错误/保留策略；未配置备份目录明确报错。
- 审计日志只追加：登录、规则发布、记分、复核、冲正/更正、申报审核、申诉裁决、账号与范围变更、导入、备份、分享创建/撤销、证据上传等。

### 响应式与前端体验

- 手机底部导航 + 抽屉导航、卡片化列表、底部抽屉弹窗；平板双列；桌面侧边栏 + 多列图表。
- 360px 起无整页横向溢出；表单必填提示、服务端错误回显、提交中/成功/失败反馈与防重复提交；危险操作二次确认。
- 中文界面与统一术语；状态均带文字标签，不只依赖颜色。

## 技术信息

- Node.js ≥ 24，Express 5，`node:sqlite`（SQLite，单机零外部数据库依赖）。
- React 19 + TypeScript 严格模式 + Vite 6 + Tailwind CSS 4 + lucide-react + recharts。
- 认证：HttpOnly + SameSite=Lax 会话 Cookie、scrypt 密码哈希、登录失败限流、改密吊销其他会话、同源写入校验、CSP/安全响应头。
- 测试：Vitest（服务端单元/集成/e2e）+ Playwright（真实浏览器桌面与手机流程）。

## 已知限制

- 本版本不含 AI 自动评分/评语；所有积分与报告由规则与真实记录确定性计算。
- 家长身份核验依赖学校线下渠道后发放高熵链接，本版本未内置短信/统一身份认证。
- SQLite 单机部署适合单校规模；多校区/高并发建议迁移 PostgreSQL。
- 学生通过受限申报链接参与，不开放学生登录；XLSX 导入导出未实现（CSV 可用 Excel 打开）。
- 通知渠道为站内状态，未接入短信/企业微信。

## 安全提示

- 生产环境必须配置 ≥32 位随机 `APP_SECRET`，使用 HTTPS 并设置 `COOKIE_SECURE=1`。
- 不要使用演示账号与演示数据上线；首次部署通过 `npm run admin:create` 创建管理员。
- 分享链接只发给已核验身份的家长，离开学校时及时撤销；备份文件按未成年人数据管理要求保护。
